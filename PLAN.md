# Resume Delivery 2037 — веб-версия
### Интерактивное отклик-резюме геймдизайнера для Playstrom
### Смесь: «Rocket Post: смена за 3 минуты» (A) + баланс-лаборатория (B)

Статус: в разработке. Предыдущая Unity-версия убрана (история коммитов сохранена).

## 1. Идея

Рекрутер выходит на смену в пункт выдачи **Rocket Post** из вселенной *Shipping Store Simulator 2037* (новый PC-проект Playstrom). По конвейеру приезжают посылки — разделы резюме. Зажал мышь на коробке — она сканируется и открывает карточку факта. Отсканированные коробки встраиваются в башню-магазин, а в «час пик» волны роботов конкурента **QuickBox** атакуют её в духе *TDS — Tower Destiny Survive*. Между волнами — **тюнер баланса** с живой математикой (микс B). В финале башня превращается в ракету и доставляет посылку «геймдизайнер → Playstrom» с контактами.

## 2. Игровой цикл

1. **Приём** — коробка едет по конвейеру к окну сканирования.
2. **Скан** — зажать или кликнуть ~0.6 с → карточка факта CV (заголовок, 1–2 строки, теги) → **+1 очко**.
3. **Стройка** — очко тратится сразу: клик по круглой площадке у маршрута строит башню этого типа, клик по существующей башне улучшает её (уровень: +35% урона, +10% радиуса, звёздочки-пипсы).
4. **Типы башен** — определяются посылкой: пушка (Game Design), снайпер (баланс и матстатистика), пулемёт (C#), мортира (проекты), дрон-замедлитель (серия резюме и playables), усилитель соседей (образование).
5. **Тюнер** (после 3-й, 6-й, 9-й коробки) — 3 очка на урон/скорострельность/радиус всего арсенала; живой предрасчёт: суммарный DPS, число башен, прогноз «сколько прорвётся». Выбор реально меняет волну.
6. **Час пик** — роботы QuickBox идут по S-маршруту к двери магазина; башни стреляют сами, клик по роботу — буст-выстрел, замедлитель притормаживает рой.
7. **Мини-отчёт** — «Доставлено X · Помято Y · DPS Z» → следующая коробка.

10 коробок (последняя «Контакты»), 3 волны + босс «Легаси-голем». Сессия 3–4 минуты.

## 3. Отчёт смены (слой B)

После каждой волны — строка статистики. В финале — полный отчёт: сводка по волнам, карьерный таймлайн (все открытые карточки списком — «двухминутное резюме»), контакты, кнопки [Ещё смена] [Просто CV].

## 4. Правила уважения к рекрутеру

Проиграть нельзя (помятая посылка только портит «идеальную смену»); Skip в один клик → финал; «Просто CV» — текстовое резюме на странице + PDF; RU/EN переключатель; desktop-first, на узких экранах — подсказка открыть на компьютере (CV доступен всегда).

## 5. Стек и структура

Чистый веб без сборки: HTML + CSS + ES-модули, **PixiJS 8.6.6 с CDN** (родной стек кандидата — вся серия предыдущих резюме и playable-ads на JS/PixiJS). Арт — плоский вектор в изометрии: картон, скотч, неон-акценты; палитра — крем/картон + оранжевый Rocket Post против неон-голубого QuickBox.

```
index.html        — лендинг + канвас + DOM-оверлеи + секция «Просто CV»
style.css         — дизайн-код (картон/неон, модалки, слайдеры)
js/loc.js         — RU/EN словарь, переключение
js/data.js        — посылки, волны, формулы тюнера
js/game.js        — PixiJS: изометрия, сцена, состояния, бой
js/ui.js          — карточки, тюнер, HUD, отчёт, финал
js/main.js        — точка входа
docs/CV_Yaroslav.pdf
```
