# Resume Delivery 2037

Интерактивное резюме геймдизайнера — мини-смена в пункте выдачи посылок **Rocket Post** из вселенной *Shipping Store Simulator 2037*. Это шестая работа в моей серии игровых резюме (до этого были отклики для Playrix, Lesta, Top Games, Igrotech и Gametech): вместо списка достижений — механики, в которые можно поиграть.

## Как это устроено

По конвейеру пункта выдачи приезжают посылки — разделы моего резюме. Каждую нужно просканировать: под сканером — факты о навыках, проектах и опыте. Отсканированные коробки встраиваются в башню магазина, а в «час пик» на неё нападают роботы конкурента QuickBox — башня из навыков отбивается в духе tower defense. Между волнами — мини-тюнер баланса (урон / скорострельность / радиус при ограниченном бюджете очков): моя любимая часть геймдизайна в чистом виде. В финале башня превращается в ракету и доставляет последнюю посылку — мои контакты.

План и дизайн-документ: [PLAN.md](PLAN.md).

## Что внутри

- **Обёртка** — cozy-симулятор смены в духе *Shipping Store Simulator 2037* (новый PC-проект Playstrom)
- **Экшен-слой** — мини tower defense в духе *TDS — Tower Destiny Survive* (гибрид-казуальный хит Playstrom)
- **Дизайн-подпись** — тюнер баланса башни, отсылающий к моим баланс-лабораториям из прошлых резюме
- Русский / английский языки, кнопка «просто CV» для тех, кто не хочет играть, и невозможность проиграть — рекрутер не должен фейлить отклик

## Стек

Unity 6 (URP, low-poly 3D) → WebGL, HTML-лендинг. Контент (коробки, волны, карточки, локализация) вынесен в ScriptableObject'ы — правится без кода.

## Запуск

- **В редакторе:** Unity 6000.6.5f1, открыть папку проекта, сцена `Assets/Scenes/SampleScene.unity` (пока так, скоро будет своя).
- **WebGL из консоли:** `unity build . --target WebGL --execute-method BuildScript.PerformWebGLBuild` — билд ляжет в `Builds/WebGL`.

## Статус

В разработке. Сейчас готов каркас: проект, WebGL-сборка, настройки Brotli. Дальше по плану — игровой цикл (конвейер → скан → башня → волна), контент из CV, локализация, лендинг. Скриншоты появятся вместе с первым играбельным билдом.
